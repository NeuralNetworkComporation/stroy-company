# BERG HOUSE

Корпоративный сайт строительной компании BERG HOUSE.

Профиль: строительство малых гидроэлектростанций (МГЭС), гидротехнические сооружения, бетонные работы, поставка оборудования, монтаж, пусконаладка и сервисное сопровождение.

## Запуск

```bash
npm run dev
```

После запуска сервер покажет локальный адрес в терминале.

## Изображения

Все изображения хранятся локально, внешних источников нет.

- `images/preloader-bg.jpg` — фон прелоадера
- `images/stock/*.jpg` — фотографии разделов; у каждой есть уменьшенный
  вариант `*-sm.jpg` для маленьких карточек (превью в блоге)
- `brand-source/` — оригиналы логотипов в полном разрешении (в репозиторий
  не входят); в `assets/` лежат сжатые копии, которые отдаёт сайт

При добавлении новой фотографии сжимайте её перед коммитом и кладите рядом
уменьшенную версию, если она нужна в мелком блоке.

## Видео

Видео хранится локально в `video/`, внешних плееров нет.

- `video/hero-boz-uchuk.mp4` — фон первого экрана (H.264, без звука)
- собственный плеер: `js/player.js` + стили `.bhp-*` в `css/style.css`

Разметка плеера — пустая оболочка, всё остальное строит скрипт:

```html
<div class="bhp-player" tabindex="0"
     data-video-src="video/имя-файла.mp4"
     data-video-start="7"
     data-video-fallback="https://youtu.be/..."
     data-video-title="Название">
  <video preload="none" playsinline poster="images/.../poster.jpg"></video>
</div>
```

`data-video-start` — с какой секунды начинать (пропуск заставки).
Пока `data-video-src` не указан, постер работает ссылкой на
`data-video-fallback`, поэтому раздел не ломается без файла.

Кодировать в H.264 (не HEVC — он не играет в части браузеров):

```
ffmpeg -i исходник.mp4 -an -c:v libx264 -profile:v high -pix_fmt yuv420p        -crf 26 -preset slow -movflags +faststart video/имя-файла.mp4
```

Перемотка требует Range-запросов — они реализованы в `server.js`;
на стороннем хостинге убедитесь, что сервер отдаёт `206 Partial Content`.

## SEO

- `robots.txt` и `sitemap.xml` в корне; при добавлении страницы обновите
  `sitemap.xml`
- В каждой странице есть `canonical`, Open Graph и Twitter-теги; обложка для
  превью в мессенджерах — `assets/og-cover.jpg` (1200×630)
- На главной размещена разметка организации (JSON-LD, тип `GeneralContractor`)
  с адресом, телефоном и часами работы

## Кэш

Ссылки на `css/style.css` и файлы в `js/` содержат параметр `?v=ГГГГММДД-N`.
**После любой правки CSS или JS увеличьте этот номер во всех HTML-файлах**,
иначе вернувшиеся посетители до суток будут получать старую версию:

```bash
sed -i 's/?v=20260901-1/?v=20260902-1/g' index.html 404.html pages/*.html
```
